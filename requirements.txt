# The pan-African detector bundle is a pickled, fitted Pipeline, saved under
# scikit-learn 1.9. Pickles load faithfully within a minor series and are
# not guaranteed to across one, so the range is pinned to it. Patch releases
# are fine and are what CI will install.
#
# This pin is also why the Python floor is 3.11: scikit-learn 1.8+ requires
# it, and CI's own install log showed Python 3.10 resolving to 1.7.2 - a 1.9
# pickle read by 1.7 is the unsafe direction, and it fails silently.
#
# To move to 1.10: widen the range, re-save the bundle, and run its tests.
#   python scripts/build_pan_african_bundle.py --reexport
#   python -m pytest tests/test_pan_african.py

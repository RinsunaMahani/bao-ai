# The default HeuristicLanguageDetector needs none of this — this is an
# opt-in accuracy upgrade, not a requirement to run the app.
#
# ai-edge-litert is Google's standalone LiteRT runtime. It provides the only
# thing the classifier needs (a TFLite interpreter) at a fraction of the
# size of full TensorFlow, and it is packaged for newer Python versions.
#
# This matters concretely: TensorFlow publishes no wheels for Python 3.14,
# so `pip install tensorflow` there fails with "No matching distribution
# found" and the ML classifier silently never runs while the app keeps
# working on the keyword fallback.
-r requirements.txt
ai-edge-litert>=1.0.0
